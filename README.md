# Threads AI 帳號標記

在 Threads 貼文作者旁顯示名單標記，也可以選擇顯示作者個人檔案上的所在地與主題。個人名單和設定存於目前的瀏覽器，可用 JSON 備份搬到另一個瀏覽器。

我做這個專案是為了在滑 Threads 時看見自己整理的帳號名單。內建名單由人工維護，擴充功能本身不掃描照片或判定帳號是否由 AI 生成。資料用途與保存期限請見[隱私說明](PRIVACY.md)。

## 安裝

### Chrome

1. 在網址列開啟 `chrome://extensions`。
2. 開啟 **開發人員模式**。
3. 按 **載入未封裝項目**，選擇包含 `manifest.json` 的專案資料夾。
4. 開啟 Threads。若已開啟，重新整理分頁。

### Firefox

1. 在網址列開啟 `about:debugging#/runtime/this-firefox`。
2. 按 **載入暫用附加元件**，選擇專案內的 `manifest.json`。
3. 開啟 Threads。如果已開啟 Threads，重新整理該分頁。

重新啟動 Firefox 後，需要再次載入暫用附加元件。

## 使用擴充功能

1. 點開工具列上的擴充功能圖示。輸入 `@帳號` 或 Threads 個人檔案網址，再按 **搜尋**。如果目前分頁是某個帳號的貼文或個人檔案，可以先按 **帶入帳號**。
2. 選擇 **我的 AI 名單標記** 或 **白名單**，再按 **新增標記**。同一帳號只保留最後選的個人標記。在 **個人名單** 中按 **移除**，可刪除該帳號的個人標記。
3. 在 **顯示標籤** 選擇要顯示的內容。第一次安裝時，所有標籤預設開啟。所在地與主題查詢會使用目前的 Threads 登入狀態查詢畫面上的作者。可用 **個人檔案標籤** 同時切換兩種主題，也可個別勾選。用 **內建 AI 名單** 開關控制貼文旁的內建名單標記。

貼文上的內建名單與個人 AI 標記會標明來源。AI Threads 和 AI Art 是 Threads 個人檔案上的主題，單憑主題無法判定帳號是否由 AI 生成。白名單會隱藏該帳號的 AI 相關標記。關閉白名單徽章的顯示時，這個規則仍會生效。

按 **在分頁中開啟** 可以用獨立分頁管理設定。太陽與月亮按鈕可切換明暗模式。第一次使用時，配色跟隨瀏覽器偏好。

## 備份與還原

1. 在 **備份與還原** 按 **匯出我的資料**，儲存 `threads-marker-backup.json`。檔案包含個人白名單、個人 AI 標記、標籤顯示設定，以及明暗模式。
2. 要還原時，在 **還原** 方框選取備份檔，確認預覽中的帳號數量。
3. 選 **合併名單** 或 **取代個人名單**，再按 **確認匯入**。合併時，同一帳號以備份中的個人標記為準。取代時，備份中的兩份名單會取代目前的個人名單。兩種方式都會套用備份中的設定。

備份不包含內建名單、查詢快取或 Threads 登入資料。

## 維護內建名單

編輯 [`data/threads_list.txt`](data/threads_list.txt)，每行填一個帳號。可使用 Threads 個人檔案網址或 `@帳號`。

```text
https://www.threads.com/@example
@example
```

以 `#` 開頭的行會被視為註解。
